# Expense Tracker Application

A full-stack Personal Expense Tracker application built with Node.js, Express, and interactive chart analytics to manage income, expenses, and balance calculations in real time.

## Features
- Real-time Total Balance, Income, and Expense calculations
- Interactive Category Analytics Chart
- In-memory data management for fast updates

## Tech Stack
- **Backend:** Node.js, Express
- **Frontend:** HTML, CSS, JavaScript (Chart.js)

## How to Run Locally
1. Clone the repository
2. Install dependencies: `npm install`
3. Run the server: `node server.js`
4. Open `http://localhost:5000` in your browser
